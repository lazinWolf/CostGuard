How it works

  1. Run both prompts on the same cases
  2. Price both on one catalog
  3. Apply your limits: pass, fail or inconclusive
  4. An analyst model explains and proposes a fix
  5. Run the fix and compare with the baseline

The same verdict gates CI: python -m costguard gate --baseline … --candidate … --pricing … --policy … exits 0 for pass, 1 for fail, 2 for inconclusive. Models are reached through the Bifrost gateway, local (Ollama) or cloud.
